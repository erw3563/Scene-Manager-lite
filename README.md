# Scene-Manager-lite

这是一个基于原项目 https://github.com/maktoobgar/scene_manager?tab=MIT-1-ov-file  Scene Manager 裁剪得到的个人精简版本。

我在自己的 Godot 项目中只需要其中的转场效果，而不需要完整的场景管理功能，因此移除了场景管理相关部分，只保留了转场动画相关内容。

这个仓库主要用于：

- 我自己的项目使用
- 方便只需要转场功能的人直接取用
- 作为原项目的精简派生版本保存

## 原项目

原项目：

[https://github.com/maktoobgar/scene_manager](https://github.com/maktoobgar/scene_manager?tab=MIT-1-ov-file)

原作者项目采用 **MIT License**。

非常感谢原作者。

## 本版本做了什么

本版本主要进行了裁剪，而不是重新实现。

主要变化包括：

- 移除场景管理相关功能
- 保留转场动画相关功能
- 保留转场资源与必要依赖
- 为我的项目使用方式进行了简单整理

除此之外，没有对原项目进行大规模重写。

如果你需要完整的场景管理功能，请直接使用原项目。

## 为什么做这个版本

我自己的项目已经有场景管理方案，因此只想单独使用原项目中的转场效果。

直接保留整个 Scene Manager 对我的项目来说没有必要，所以做了这个精简版本。

如果你也只需要转场功能，这个版本可能会更方便。

## 使用方式

将本仓库中对应的插件目录复制到你的 Godot 项目中的插件目录。

然后根据项目实际结构启用或引用对应的转场功能即可。

具体目录和使用方式后续可能会根据我的项目调整。
